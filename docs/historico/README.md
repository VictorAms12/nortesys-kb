# Arquivo histórico — versões anteriores

Esta pasta reúne relatórios e checklists das versões anteriores do Nortesys KB, **preservados somente para consulta histórica**. Ela não define o procedimento atual de deploy, migrations, segurança, login ou testes.

- Para iniciar o projeto: [README do projeto](../../README.md).
- Para operar o banco e as migrações: [Configuração](../guias/configuracao.md).
- Para publicar Preview/Production: [Deploy](../guias/deploy.md).
- Para testar o navegador: [Testes Playwright](../guias/testes-navegador.md).

Os documentos antigos podem mencionar scripts, branches, credenciais fictícias ou instruções descontinuadas. Use os guias ativos em `docs/guias/`. O histórico foi **arquivado em vez de apagado** para preservar rastreabilidade, sem o manter na navegação operacional.
