NORTESYS KB - FASE 5: CORRECAO DO ERRO "ORIGEM INVALIDA" (HTTP 403)

Motivo: a rota de login comparava o cabecalho Origin com req.nextUrl.origin.
A URL interna calculada pelo Next.js pode divergir do Host que o navegador usa.

Correcoes neste ZIP:
- src/lib/origem.ts: confere Origin x Host (mesmo protocolo/host/porta do navegador), rejeitando cross-site e cabecalhos ausentes.
- src/app/api/autenticacao/entrar/route.ts: usa validacao corrigida e redireciona para origem real do navegador.
- src/app/api/autenticacao/sair/route.ts: evita erro identico no logout e usa origem real no redirecionamento.
- tests/testar-seguranca.ts: testa casos locais, producao e tentativas cross-site.

COMO INSTALAR:
1. Feche o servidor do Next com Ctrl+C.
2. Extraia este ZIP na RAIZ do projeto (onde esta package.json), substituindo os arquivos.
3. NAO substitua nem envie o arquivo .env.local; senhas e segredos permanecem os mesmos.
4. No PowerShell do VS Code execute:
   npm.cmd run testar:seguranca
   npm.cmd run lint
   npm.cmd run build
   npm.cmd run dev
5. Acesse http://localhost:3000/entrar e tente entrar e sair.

Se continuar dando HTTP 403, verifique se acessou o mesmo host e porta que
aparecem no navegador e se um proxy reverso preserva o cabecalho Host.

IMPORTANTE: Nao remova a verificacao de origem nem use coringas para liberar origens.
